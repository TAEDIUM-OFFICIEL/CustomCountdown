# Custom Countdown for Revenge

🇫🇷 **Version Française**
Un plugin de compte à rebours 100% personnalisable pour le client Discord Revenge.
Ce plugin est une version modifiée et améliorée par [TaediumBreak](https://github.com/TAEDIUM-OFFICIEL).
Le code de base original a été créé par [Purple_EyeZ](https://github.com/Purple-EyeZ) (un grand merci à lui !).

### Comment l'installer ?
Copiez le lien ci-dessous et collez-le dans la page Plugins de Revenge :
`https://taedium-officiel.github.io/CustomCountdown/dist/GTAVICountdown`
*(Si le lien ci-dessus ne fonctionne pas sur votre version, essayez avec `/plugins/` au lieu de `/dist/`)*
